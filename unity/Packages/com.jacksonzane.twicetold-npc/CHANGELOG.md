# Changelog

Notable changes to this package. The format follows Keep a Changelog, and the
package follows Semantic Versioning.

## [0.1.0] - 2026-09-12

### Added

- Initial package: the engine-agnostic `NpcMemory.Core` (client, session, wire
  models, serializer settings) and the `NpcMemory.Unity` MonoBehaviour adapter,
  previously shipped as a committed DLL plus loose project scripts.
- First NPC sample with the `link.xml` required for IL2CPP builds.
